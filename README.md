# Thijs Verlangen — Website

Persoonlijke website voor Thijs Verlangen (spreker, vermogensstrateeg, auteur).
Gebouwd met Vite + React + TypeScript.

## Lokaal draaien

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Build

```bash
npm run build
```

Output komt in `dist/`.

## Deploy

Compatibel met Lovable, Cloudflare Pages, Vercel en Netlify. Build command: `npm run build`, output directory: `dist`.
